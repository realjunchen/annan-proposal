安南當舖｜社群經營企劃・GitHub Pages 上傳版

1. 解壓縮 ZIP。不要只上傳 ZIP 本身。
2. 建議使用新的專用儲存庫，例如 annan-proposal，避免覆蓋其他網站。
3. 將本資料夾內的檔案全部上傳到儲存庫最外層，不需要建立 assets 資料夾。
   手機可以分批選檔上傳，所有影片、圖片、字型、CSS、JS 都必須上傳。
   首頁檔名必須保留 index.html；檔名大小寫不要改。
4. GitHub 儲存庫 Settings → Pages → Deploy from a branch。
   選擇 main 分支與 /(root)，按 Save。
5. 等待 GitHub Pages 部署完成，再使用 Settings → Pages 顯示的網址。
   分享的是網站網址，不是儲存庫網址或 index.html 原始碼網址。

重點：
- 首頁為約5分45秒提案影片；後面另有48秒演算法觀念影片。
- 每支影片均小於25MiB，適合以瀏覽器分檔上傳。
- 全部影片為相對路徑，適用 GitHub Pages 的儲存庫子路徑。
- 本頁可直接開啟 index.html 預覽；影片音訊由使用者自行點擊播放。
- 介紹頁、留言自動化與LINE按鈕為提案示範，沒有串接真實店家帳號。
- 提案包含報價；正式分享前請確認版本。
- GitHub Pages 一般是公開網站，取得網址的人可以瀏覽。
